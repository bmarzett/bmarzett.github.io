# Brandon Marzett — E-Commerce Website V1

## Files
- index.html — complete one-page website
- styles.css — responsive styling
- script.js — mobile navigation

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `index.html` with your real email address.
2. Replace or add your LinkedIn URL if desired.
3. Add a professional headshot if desired.
4. Review the accomplishments and numbers for accuracy before publishing.
5. Upload the three files to your web host.
